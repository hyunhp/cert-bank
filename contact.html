Reporting a wrong answer

Please include the exam code and the question id (for example SAA-C03 Q000123, shown on every question card), what you think is wrong, and a link to the vendor documentation if you have one. Corrections are made in place, and the exam's page lists them under its recent changes.

If you prefer, you can also open a GitHub issue.

Languages
