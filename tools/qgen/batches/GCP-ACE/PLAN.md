# GCP-ACE batch plan (topics owned per batch)

Exam: Google Cloud Associate Cloud Engineer, standard exam guide read 2026-10-30. 2 hours, 50-60 questions, pass mark
not published. Target 250 (D1 50, D2 75, D3 75, D4 50). Rules: `tools/qgen/GCP.md` (current product names, no prices,
nothing preview or retired keyed, commands checked on docs.cloud.google.com).
Shared hot spots belong to ONE batch only; others may use them as distractors but not as the tested concept.
