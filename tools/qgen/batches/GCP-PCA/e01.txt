@ Q009002 explain
G: ## AI-assisted operations
Gemini Cloud Assist is an AI collaborator across the application lifecycle: designing, deploying, troubleshooting and optimizing. For troubleshooting it offers:
- **Investigations**: AI-driven analysis that ingests logs, metrics and configuration, explores hypotheses in parallel and traces root causes across multi-tier topologies.
- **Proactive alert investigations**: an alerting policy can trigger Gemini Cloud Assist automatically; it analyzes the issue in the background, clusters related alerts and generates a preliminary root-cause analysis with recommended next steps.
- **Support handoff**: investigation results can be passed to Google Cloud support as context.
It builds on the signals you already collect; it does not replace alert definitions or human judgment.
## Availability
Gemini Cloud Assist capabilities differ in availability. Google's product page (cloud.google.com/products/gemini/cloud-assist, read 2026-10-31) labels the investigations tool and proactive investigations "private preview" and says Gemini Cloud Assist is in preview, while the documentation overview (docs.cloud.google.com/gemini/docs/cloud-assist/overview) shows no preview label on them. The exam guide names Gemini Cloud Assist, so know what each capability does, and check the current status before relying on it.

G: ## Gemini Cloud Assist across the lifecycle
Gemini Cloud Assist is an AI collaborator in Google Cloud that supports several phases of the application lifecycle:
- **Design and build**: natural-language architecture design in Application Design Center, Terraform and gcloud generation, IAM assistance.
- **Support and troubleshoot**: investigations that analyze logs, metrics and configurations to find root causes, proactive alert investigations, database and application troubleshooting.
- **Optimize**: cost questions in natural language, FinOps Hub analysis, **proactive cost anomaly analysis**, database optimization, network flow analysis, and storage insights.
## Pillar link
The question is about the cost optimization pillar: understanding spend, finding waste, and explaining changes. Choose the Gemini Cloud Assist capability from the matching lifecycle area. Output from any AI assistant is still reviewed by a person before it drives a decision.
