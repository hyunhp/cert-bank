@ DBX-DEA D6 T6.2 applied troubleshooting
S: A job has tasks `extract`, `transform` and `load`, and a side task `notify` that depends on `extract` and is a leaf. In one run, `transform` fails with an error, `load` is not run, and `notify` succeeds. How does Lakeflow Jobs determine the status of the run?
A: Succeeded, because the status comes from the first task `extract`, which finished correctly and started the others
B: Succeeded with failures, because the leaf task `notify` finished correctly after the failure in `transform`
C: Skipped, because the leaf task `load` was not run, and a skipped leaf task makes the whole run skipped
D: Failed, because the leaf task `load` did not succeed, and the run status is decided by the leaf tasks
K: D
G: ## How the run status is determined
Databricks decides whether a run was successful from the outcome of its **leaf tasks**, which are tasks with no downstream dependency. The outcomes are:
- **Succeeded**: all tasks were successful.
- **Succeeded with failures**: some tasks failed, but all leaf tasks were successful.
- **Failed**: one or more leaf tasks failed.
- **Skipped**, **Timed Out**, **Canceled** for runs not started, exceeding time, or stopped.
## This scenario
Leaves are `load` and `notify`. `notify` succeeded, but `load` never ran because its upstream `transform` failed, so a leaf did not succeed and the run is Failed.
W: Failed: the run status is decided by the leaf tasks, and the leaf task `load` did not succeed because its upstream task failed, so the run is Failed even though `notify` succeeded.
X: A=First task: status is not taken from the first task; it depends on the leaf tasks of the dependency graph.
B=Succeeded with failures: that status needs every leaf task to be successful; `notify` succeeded, but the other leaf `load` did not complete successfully.
C=Skipped: a skipped run is one that was never started, for example for exceeding maximum concurrent runs; here the run started and had a failing task.
T: Run status is decided by leaf tasks: any failed or unrun leaf makes the run Failed, and Succeeded with failures needs all leaves to succeed.
