@ GCP-CDL D1 T1.1 applied definition
S: A health-technology company wants to build its data platform on Kubernetes, a project whose source code is published for anyone to inspect, modify and share under a license that allows this. A board member asks what "open source" means for the company in business terms. Which answer is correct?
A: Its code may be studied, changed and redistributed by anyone, so a community contributes and dependence on one vendor shrinks
B: It is free to run in production, so the company is not allowed to pay anyone for support, hosting or managed services around it
C: It is a specification certified by a standards body, and vendors are required to implement it the same way in their products
D: It has to run on hardware the company owns, because its license forbids placing the code on a cloud provider's servers
K: A
G: ## What open source means
Open-source software is software whose source code is made publicly available under a license that lets people view, change and share it. Projects are usually developed with a community of contributors. Kubernetes, the container orchestration system behind Google Kubernetes Engine (GKE), is a well-known example that began at Google.
## Why a business cares
- **Portability**: an application built on open-source technology can run in several environments, which reduces dependence on one vendor.
- **Community innovation**: improvements come from many contributors.
- **Transparency**: the code can be inspected.
Google describes multicloud solutions built on open-source technologies like Kubernetes as providing the flexibility and portability to migrate, build and optimize applications across clouds and computing environments.
## Do not confuse
Open source concerns the availability of code. A formal agreed specification published for everyone to implement is an open standard.
W: Code anyone can study, change and redistribute: this is the definition, and the business benefit is community contribution and less dependence on one vendor.
X: B=Free and no paid support: open-source code can be used without a license fee, but vendors sell managed services and support for it, so paying someone is allowed.
C=Standards-body specification: that describes an open standard, which is a published specification, not the availability of code.
D=Company hardware: open-source software can run on any suitable infrastructure, including cloud providers, and Kubernetes is run on clouds at scale.
T: Open source = publicly available code anyone can inspect, modify and share; its business value is portability and community innovation.
V: Kubernetes, GKE

@ GCP-CDL D1 T1.1 applied comparison
S: A retailer's security chief doubts that a small in-house team can protect customer data better than a cloud provider can. A consultant lists what the cloud adds to security. Which TWO statements about cloud security are correct? (Select TWO)
A: Cloud security is generally regarded as stronger than typical enterprise data centers, given the depth of its built-in mechanisms
B: A provider's security teams are widely regarded as top experts in the field, and the customer benefits from the work they do
C: Moving to the cloud lets the customer disband its security team, because the provider takes over responsibility for the controls
D: Cloud providers do not offer encryption services, so customers need to buy a separate product to protect their data at rest
E: Security risks are the same in any environment, so the choice of provider has little influence on a company's overall risk
K: A,B
G: ## Enhanced security as a cloud benefit
Google's description of cloud computing says that security risks are considered relatively low and that cloud computing security is generally recognized as stronger than that in enterprise data centers, because of the depth and breadth of the security mechanisms providers put in place. Providers also employ security teams known as top experts in the field.
Google Cloud adds its own point: customers benefit from the same security capabilities Google uses to protect its own users, with frontline intelligence, a modern security operations platform, and a secure-by-design, secure-by-default infrastructure.
## Shared responsibility
Security is still shared. The provider secures the underlying infrastructure; the customer remains responsible for how it configures and uses services, its identities and its data.
W: A=Stronger mechanisms: the breadth and depth of protections built into a provider's platform are why cloud security is generally regarded as stronger than that of most enterprise data centers.
B=Expert security teams: the customer gets the work of a provider's specialists, which a small in-house team could not match on its own.
X: C=Disband the security team: responsibility is shared; the customer still manages identities, configurations and data, so its security team stays necessary.
D=No encryption services: providers do offer encryption services; protecting data is part of the security mechanisms providers build in.
E=Same risk in any environment: environments and providers differ in the controls and expertise they offer, which is the reason cloud can improve security.
T: Cloud security benefits from a provider's built-in mechanisms and expert teams, while responsibility remains shared.
V: Google Cloud

@ GCP-CDL D2 T2.3 advanced use-case
S: A credit-card company reviews transactions for fraud in a nightly batch job. Fraudsters often make many purchases within minutes, so most losses happen before the next morning's review. Executives ask why the company should invest in real-time streaming analytics. Which TWO statements describe the value? (Select TWO)
A: It lets the company drop historical data, because fraud decisions depend on the most recent transaction alone
B: Each event is evaluated as it arrives, so suspicious activity can be flagged and acted on in seconds rather than hours
C: It prevents fraudulent transactions from being approved, so the company can retire its fraud review process
D: Responses can be based on current data, such as blocking a card or alerting the cardholder at that moment
E: It depends on copying the transaction data into a spreadsheet each night so that analysts can review it
K: B,D
G: ## Batch vs streaming
- **Batch analytics** collects data over a period and processes it later, for example nightly. Results describe the past.
- **Streaming (real-time) analytics** processes each event as it arrives, so results describe the present.
The business value of streaming is **timeliness**: when the value of an action falls quickly with time, such as stopping fraud, rerouting a delivery or adjusting a price, waiting for a batch means missed opportunity or avoidable loss.
## What streaming does not do
It does not replace historical analysis (models are often trained on history), and it does not make risk disappear. It shortens the time between an event and a response.
W: B=Evaluation as events arrive: acting within seconds rather than hours is the central benefit and addresses losses that happen in the minutes before a nightly review.
D=Responses on current data: real-time insight enables immediate responses, such as blocking a card or alerting the customer.
X: A=Drop historical data: historical data is still valuable for trends and for training detection models; streaming adds current data to it.
C=Prevents fraud outright: analytics reduces and speeds up the response to fraud; no technology guarantees that fraud never happens, so review processes stay.
E=Nightly spreadsheet: this is the opposite of streaming, since data is analyzed continuously and not once a night in a spreadsheet.
T: Streaming analytics turns data into action while it still matters, which cuts losses and improves customer experiences.
V: Pub/Sub, Dataflow, BigQuery
