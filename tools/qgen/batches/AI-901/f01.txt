@ AI-901 D2 T2.1 applied troubleshooting
S: A developer's prompt starts with "Summarize the key points as a bulleted list," followed by a long meeting transcript. The model often returns a paragraph instead of bullets. Using techniques from Microsoft's prompt engineering guidance, what should the developer try first?
A: Set the temperature to its maximum so that a more random model is likelier to try other formats such as lists
B: Remove the instruction and rely on the transcript's own structure, since models default to bulleted summaries
C: Restate the instruction after the transcript and end the prompt with a cue that begins the first list item
D: Send the transcript in many requests, one sentence each, and join the replies into a bulleted list in the app
K: C
G: ## Order matters: recency bias
Learn's prompt engineering guidance notes that models can show **recency bias**: information at the end of a prompt can influence the output more than information at the beginning. With a long transcript in the middle, an instruction at the very top can lose its effect. Two documented techniques help:
- **Repeat instructions at the end**: give the instruction before and after the primary content ("double down").
- **Use a cue**: end the prompt with a few words the model builds on. Learn's example is a cue like `Here's a bulleted list of key points:\n- `, which "can help make sure the output is formatted as a list of bullet points."
## Prompt parts in Microsoft's terms
- **Instructions**: what to do.
- **Primary content**: the text to process (the transcript).
- **Cue**: the jump-start for the output.
- **Supporting content**: extra context such as the current date.
W: Restate the instruction and add a cue: restating the instruction after the long transcript counters recency bias, and a cue such as a heading followed by a first "- " bullet gives the model the start of the format it should continue.
X: A=Maximum temperature: temperature adds randomness to word choice. It doesn't steer the model toward a specific format and can make the output less coherent.
B=Remove the instruction: without any instruction the model has even less reason to use bullets; nothing makes lists the default format.
D=One sentence per request: summarizing single sentences loses the overall meaning of the meeting and multiplies requests, and joining the replies in the app doesn't fix how the model formats them.
T: When a long input buries the instruction, repeat the instruction after the content and end with a cue that starts the desired format.

@ AI-901 D1 T1.3 applied use-case
S: A multi-storey car park has a ceiling camera over each row of bays. The operator wants software that looks at the live camera images, finds which bays have a car in them and shows the number of free spaces on each floor's entrance sign. Which AI workload matches this need?
A: Computer vision, using object detection to locate vehicles in each frame and compare them with bay positions.
B: Speech, using speech recognition to transcribe drivers asking for a free bay at each floor's entrance intercom.
C: Text analysis, using entity detection to find the bay numbers and floors that drivers mention in online reviews.
D: Information extraction, using an analyzer to read bay numbers and times from the tickets issued to each car.
K: A
G: ## Computer vision
Computer vision is the area of AI that analyzes **visual input**: photographs, videos and live camera feeds. Models are trained with large numbers of images. Microsoft Learn describes several model types:
- **Image classification**: predicts the main subject of an image ("this is a car").
- **Object detection**: identifies the **location** of specific objects in an image, usually as a bounding box.
- **Semantic segmentation**: an advanced form of object detection that marks the individual pixels belonging to an object.
- **Multimodal models**: combine visual features with text so they can describe images in natural language.
## Typical scenarios
Auto-captioning and tagging photos, visual search, monitoring stock levels on shelves, security video monitoring, facial recognition for authentication, robotics and self-driving vehicles, and agents that interpret visual input.
## Example
For one camera frame, an object detection model returns boxes such as "car, confidence 0.95, at x=120,y=40"; the app compares the boxes with the known bay positions, finds 3 of 12 bays empty and updates the sign.
W: Computer vision: the input is live camera images and the requirement is to find where cars are, which is the "locate objects in an image" task that object detection models perform.
X: B=Speech recognition: transcribing a spoken request captures what a driver asks for, while the goal is to have software see which bays are empty.
C=Entity detection: it finds named things in written text, but reviews describe past visits and say nothing about which bays are occupied right now.
D=Information extraction: reading parking tickets returns when cars arrived, yet a ticket does not show which bay is free at this moment.
T: When the input is images or video and the goal is to recognize or locate what is in them, the workload is computer vision.
