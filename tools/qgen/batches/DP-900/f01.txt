K: A
G: ## Real-Time hub
The **Real-Time hub** is the centralized catalog of streaming data in Microsoft Fabric. It makes it easy to find, add, explore and share data in motion.
It contains:
- **Data streams**: the eventstreams and other streams running in Fabric that you have access to.
- **Microsoft sources**: streaming sources you can connect, such as Azure Event Hubs, Azure IoT Hub and change data capture from Azure SQL Database or Azure Cosmos DB.
- **Fabric events**: events from Fabric items and from Azure Blob Storage that can trigger actions.
Sharing streams through the hub lets teams in different domains build analytics on each other's real-time data.
## Example
A logistics analyst opens the Real-Time hub, finds the "warehouse door sensors" stream published by facilities, and sends it to her own eventhouse.

C=Eventhouse: an eventhouse stores and queries event data; it does not merge the teams' streams into one table or catalog them, and teams keep their own databases.
D=OneLake: OneLake is Fabric's storage layer; streams are discovered in the Real-Time hub, and events are not stored as CSV folders by default.
