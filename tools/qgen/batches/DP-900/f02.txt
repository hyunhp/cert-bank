G: ## Core components of Azure Databricks
- **Lakehouse on Delta Lake**: the storage layer for SQL analytics and machine learning.
- **Databricks SQL**: SQL warehouses that run analytical queries directly against Delta tables, with query history, dashboards and alerts.
- **Notebooks**: collaborative Python, SQL, Scala and R notebooks for engineering, exploration and machine learning.
- **Lakeflow pipelines**: a declarative way to build reliable, incrementally updated pipelines on Delta Lake.
- **Unity Catalog**: the **unified governance layer** for data and AI assets, with **fine-grained access control, data lineage and discovery**.
## Governance in practice
Administrators grant permissions on catalogs, schemas, tables and views with access control lists, through the UI or SQL. Sharing a table inside the organization can be as simple as granting query access to it.

S: A bank needs its managed SQL Server databases to use private IP addresses inside its own Azure virtual network, with connectivity to on-premises over ExpressRoute, and it relies on instance-level features. Which service fits best?
A: SQL Server on Azure Virtual Machines in a public subnet, with the OS firewall open to on-premises clients.
B: Azure Database for MySQL flexible server, deployed with private access into the bank's virtual network.
C: Azure SQL Managed Instance, a PaaS SQL Server instance that is deployed into a subnet the bank chooses.
D: Azure SQL Database single databases, reached from on-premises through the logical server's firewall rules.
K: C
G: ## Networking in the Azure SQL family
- **Azure SQL Managed Instance** is deployed into a subnet of your Azure virtual network. It has a native VNet implementation and a private IP address, and you can connect it to on-premises with ExpressRoute or VPN Gateway.
- **Azure SQL Database** is reached through its logical server endpoint; private IP access is added with Azure Private Link.
- **SQL Server on Azure VMs** also lives in your virtual network, but it is IaaS that you manage yourself.
## Why banks like Managed Instance
A native VNet with private addresses addresses common security concerns, and as PaaS the instance is patched and backed up by Microsoft while keeping instance-level SQL Server features.
W: SQL Managed Instance: Learn highlights its native virtual network implementation with private IP addresses and connectivity to on-premises through ExpressRoute or VPN Gateway, plus near-100% SQL Server compatibility, including instance-level features, as a managed service.
X: A=VM in a public subnet: exposing the server publicly is the opposite of the requirement, and a VM is IaaS rather than a managed service.
B=MySQL flexible server with private access: it can sit in a virtual network, but it runs MySQL, not SQL Server, so the bank's SQL Server databases and instance features would not carry over.
D=Single databases through firewall rules: firewall rules on a public endpoint do not give private addresses in the bank's network, and single databases do not offer instance-level features.
T: Managed SQL Server with private IPs in your own VNet and instance features → Azure SQL Managed Instance.
V: Azure SQL Managed Instance

@ DP-900 D1 T1.2 applied definition
S: A hospital stores X-ray images, recorded dictation and PDF reports. These files hold raw binary data that applications must interpret and render, rather than text mapped to readable characters. What do data professionals commonly call files like these?
A: Column families, because each file keeps its related raw bytes together in one named group.
B: Delimited files, because each image and recording is split into fields by a separator character.
C: Binary large objects (BLOBs), the usual name for unstructured media and document files of this kind.
D: Fixed-width files, because each image and recording uses a set number of characters per field.
K: C
G: ## Text formats and binary formats
All files are ultimately stored as binary data (1s and 0s).
- In **human-readable** formats such as CSV, JSON and XML, the bytes map to printable characters through a character encoding such as ASCII or Unicode.
- Other files, especially **unstructured data**, store **raw binary** that an application must interpret and render: images, video, audio and application-specific documents.
## BLOBs
Data professionals often call such files **BLOBs (binary large objects)**. Azure's object store for this kind of data is named after them: **Azure Blob Storage**.
## Example
A chest X-ray saved as an image file is millions of bytes that only an image viewer turns into a picture; opening it in a text editor shows unreadable characters.
W: BLOBs: images, audio, video and application documents stored as raw binary that applications must render are commonly referred to as binary large objects.
X: A=Column families: a column family is a group of related columns in a column-family database, not a name for binary files.
B=Delimited files: delimited text is human-readable data split into fields by commas, tabs or spaces; images and recordings have no such fields.
D=Fixed-width files: fixed-width is a delimited-text variant that gives each field a set number of characters; it describes tabular text, not media files.
T: Raw binary content such as images, audio and video = BLOBs (binary large objects).
V: Azure Blob Storage
