G: ## Distributed tracing
A request that passes through several services has one total latency but many parts. **AWS X-Ray** records a trace for each request: a segment for each service and subsegments for downstream calls, each with start time, duration and errors.
- Enable tracing on the API Gateway stage and active tracing on the Lambda function.
- Instrument the AWS SDK clients in the function (X-Ray SDK or AWS Distro for OpenTelemetry), so calls to Bedrock Knowledge Bases (`Retrieve`), Bedrock Runtime (`InvokeModel`) and DynamoDB (`PutItem`) each appear as subsegments.
## Reading the result
The trace timeline shows, for example, retrieval 180 ms, generation 2.4 s, DynamoDB write 12 ms. Comparing traces from several weeks ago with today's, or using trace analytics and the service map, shows which subsegment grew. Only then do you know whether to tune retrieval, the model call or the database.
Note: the AWS X-Ray SDKs and the X-Ray daemon entered maintenance mode on 2026-02-25 (security fixes only), and AWS recommends OpenTelemetry (AWS Distro for OpenTelemetry) for new instrumentation. X-Ray itself, active tracing and the trace console are unchanged, and exam questions may still name the X-Ray SDK.
W: X-Ray across API Gateway, Lambda and downstream calls: tracing breaks the end-to-end time into per-stage durations, so the stage whose latency crept up is identified directly instead of guessed.
X: A=Raise reserved concurrency: concurrency controls how many invocations run at once. It does not make any single stage faster and gives no information about which stage slowed down.
C=Assume a model update and switch models: this guesses at the cause; if retrieval or the database is the slow stage, switching models changes quality and cost without fixing latency.
D=Reduce DynamoDB read capacity: the pipeline writes results, reading capacity is not the issue, and lowering capacity can only add throttling. It diagnoses nothing.
T: Measure before you optimize: distributed tracing shows per-stage latency so you fix the stage that actually slowed down.
