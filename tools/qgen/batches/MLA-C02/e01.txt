G: ## SageMaker Clarify foundation model evaluations
SageMaker Clarify includes **foundation model (FM) evaluations**, built on the open-source **fmeval** library. They can run from SageMaker Studio or from code, for example in a pipeline step, against SageMaker AI endpoints, JumpStart models or Bedrock models.
Evaluation dimensions include:
- **Accuracy** for tasks such as summarization, question answering and classification (with metrics such as ROUGE, METEOR, BERTScore, F1 and exact match).
- **Factual knowledge**.
- **Prompt stereotyping**: does the model prefer stereotyped sentences about groups?
- **Semantic robustness**: does output change when the input gets small, meaning-preserving perturbations such as typos or extra spaces?
- **Toxicity**: scored with toxicity detector models.
Built-in datasets exist for these tasks, and you can bring your own.
## How it differs from other Clarify features
Pre-training and post-training bias metrics and Model Monitor bias drift mainly target tabular models and their predictions; FM evaluations target generated text.
## Availability
Amazon SageMaker Clarify is no longer open to new customers (AWS documentation, as of 2026-11). Existing customers can keep using it, including foundation model evaluations, as normal; AWS plans no new features and names Amazon Bedrock Evaluations as the replacement for Clarify's FMEval capability. The exam guide still lists Clarify, so exam questions treat it as the SageMaker AI capability for model evaluation, bias detection and explainability.
W: Clarify FM evaluations with fmeval: they provide built-in prompt stereotyping, toxicity and semantic robustness evaluations with built-in datasets, and the library can be called against the endpoint from a pipeline step.
X: A=Model Monitor bias drift: it watches bias metrics of a deployed tabular model over time, not stereotyping or robustness of generated text before release.
B=Pre-training bias metrics: these describe imbalance in a labeled tabular training dataset and say nothing about how the model's generated text behaves.
C=Bedrock Guardrails content filters: guardrails block harmful content at runtime; they do not produce a pre-release evaluation report on stereotyping or robustness.
T: To benchmark a foundation model for accuracy, stereotyping, toxicity or robustness, use SageMaker Clarify FM evaluations (fmeval).
