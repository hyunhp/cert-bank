@ DBX-DAA D4 T4.1 applied comparison
S: A workspace has Genie Code and many AI/BI Genie Agents. A data analyst needs to debug a failing JOIN in a notebook. Which choice is the best tool?
A: The query history page, because it fixes failed statements after sorting them by user
B: Genie Code in the notebook, because it works with the code and its errors
C: A Genie Agent, because it exposes a chat that rewrites notebook cells in place
D: A scheduled alert, because it can be set to rewrite the failing JOIN when it triggers
K: B
G: ## Matching tools to tasks
Genie Code is integrated into notebooks and the SQL editor. It sees the code you are working with, plus Unity Catalog metadata, and can explain or fix it.
A Genie Agent (called a Genie space before the rename) answers business questions over curated datasets in natural language; it is not an editor assistant. Query history lists past executions for review, and alerts watch query results against a threshold. Neither repairs code.
W: Genie Code: it is the assistant that works on the code in the notebook, including error diagnosis and fixes.
X: A=Query history: it records what ran, which helps in review and analysis, but it does not correct statements.
C=Genie Agent: agents answer data questions on trusted datasets for consumers. They do not edit notebook cells.
D=Scheduled alert: alerts evaluate a query against a condition and notify. They do not change code.
T: Fixing code in an editor: Genie Code; asking curated data questions: a Genie Agent.

@ DBX-DAA D1 T1.1 applied use-case
S: Analysts want to ask questions such as "which region had the highest revenue last quarter?" in plain English and get answers from governed tables, without writing SQL. Which platform component is designed for this?
A: A materialized view that stores the answers to every possible question and refreshes them each night
B: A Lakeflow Connect connector that rewrites business questions into ingestion queries on the source systems, then loads the answer
C: An AI/BI Genie Agent that translates natural language questions into SQL over the datasets it was configured with
D: A Photon-enabled warehouse, which interprets English text natively once the table comments are filled in
K: C
G: ## Natural language on governed data
Databricks uses AI with the lakehouse to understand the semantics of your data. **AI/BI Genie Agents** (formerly Genie spaces) let business users ask questions in natural language; Genie generates SQL, runs it on a SQL warehouse and shows the result, within the datasets and Unity Catalog permissions of the agent. **AI/BI dashboards** are the visual counterpart. **Genie Code** (formerly Databricks Assistant) helps write and debug code.
A connector, a materialized view or Photon cannot interpret questions: they ingest, store or execute.
W: Genie Agent: it turns natural language into SQL over curated datasets, so non-SQL users can self-serve answers.
X: A=Materialized view: it precomputes one defined query, so it cannot answer arbitrary questions typed by users.
B=Lakeflow Connect: connectors bring data in from sources and do not answer business questions.
D=Photon: Photon accelerates execution of SQL and has no language understanding, whatever the table comments say.
T: Genie Agents = natural language to SQL on governed data; dashboards = visuals; Genie Code = coding help.
