G: ## summary versus describe
- `df.describe(*cols)` computes count, mean, stddev, min and max for the listed columns (all numeric and string columns by default).
- `df.summary(*statistics)` computes the same, plus approximate percentiles. Without arguments it returns count, mean, stddev, min, the 25%, 50% and 75% percentiles, and max. Pass names to choose: `summary("count", "50%", "max")`.
Both are meant for exploration; the schema of the result is not guaranteed to be stable, so do not build pipelines on them.
W: summary takes statistic names: count, mean, stddev, min, max and percentages such as 50%. The median is the 50% percentile.
X: A=describe output: describe has no percentile rows, so the median row never exists in its result.
B=One value: the median function returns a single value. It does not add a count or a maximum.
C=Column names: describe takes column names. These strings are looked up as columns and fail to resolve.
T: summary(*statistics) chooses statistics including percentiles; describe takes columns instead.
