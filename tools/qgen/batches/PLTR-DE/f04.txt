G: ## Pipeline-layer AI
The exam guide places batch, reusable enrichment in the pipeline layer under the data engineer, and interactive agents under AI engineering.
- Supplier-name normalization nightly, validated, feeding an object type: data engineering.
- Agents (AIP Chatbots, built in AIP Chatbot Studio, formerly AIP Agent Studio), chat interfaces, assistant model choices: AI engineering.
Example: 50,000 supplier mentions map to 3,200 canonical suppliers each night; unmatched ones are flagged.
W: Validated nightly enrichment: a scheduled, validated batch enrichment that feeds the Supplier object type is reusable, governed, pipeline-layer AI that sits squarely in the data engineer's role.
X: A=Assistant model selection: choosing models for an assistant is the AI engineer's selection and observability domain.
B=Chat for executives: a conversational interface is interactive AI, designed and evaluated by AI engineering.
C=Ad hoc chatbot: an interactive chatbot with retrieval and tools is Ontology-layer AI owned by AI engineering.
T: Pipeline-layer AI means scheduled, validated enrichment feeding curated data and the Ontology.
V: Pipeline Builder, Ontology
