# AZ-305 batch plan (topics owned per batch)

Exam: AZ-305 Designing Microsoft Azure Infrastructure Solutions (expert; requires AZ-104). Skills as of 2026-04-17.
Target 250 (D1 69, D2 56, D3 44, D4 81). Stems are short design scenarios ("A company needs ... Which solution should
you recommend?"), not long case studies (stem-length gate). Keys must be GA; no prices.
Shared hot spots belong to ONE batch only; others may use them as distractors but not as the tested concept.
