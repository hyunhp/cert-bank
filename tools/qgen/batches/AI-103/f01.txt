@ AI-103 D4 T4.2 applied tradeoff
S: A legal firm's custom speech model is used only by a nightly job that transcribes the day's recorded depositions with the batch transcription API. Finance asks how to cut speech costs without losing the model. What should the developer recommend?
A: Delete the hosted endpoint and keep the model, because batch transcription can reference a custom model with no deployment
B: Keep the hosted endpoint, because the batch transcription API reaches a custom model through its deployed endpoint URL
C: Move the nightly job to real-time transcription, because custom models are supported by real-time recognition and not batch
D: Retrain the custom model before each nightly run, because a custom model expires a day after its training completes
K: A
G: ## Custom speech costs
Learn's custom speech overview lists separate charges for **model training** (for newer base models), **custom model usage** and **endpoint hosting**.
## Endpoints and batch transcription
To use a custom model for **real-time** speech to text or speech translation, you **deploy it to a custom endpoint**. Learn adds an exception: "Except for batch transcription, you must deploy a custom endpoint" and "A hosted deployment endpoint isn't required to use custom speech with the Batch transcription API. You can conserve resources if the custom speech model is only used for batch transcription."
## Model lifecycle
Custom and base models can be used for a limited time described in the model and endpoint lifecycle page, but that period is far longer than a day; plan updates, not nightly retraining.
W: Drop the endpoint, keep the model: batch transcription can reference the custom model directly, so an endpoint used by nothing else is a hosting cost that can be removed without losing the model.
X: B=Endpoint needed for batch: Learn explicitly exempts batch transcription from the deployed endpoint requirement; batch jobs reference the model itself.
C=Real-time instead of batch: custom models work with real-time, speech translation and batch transcription; real-time would also need a hosted endpoint, raising cost.
D=Nightly retraining: models do not expire a day after training, and retraining adds training charges without any benefit.
T: A custom speech model used only for batch transcription doesn't need a hosted endpoint, which saves hosting costs.
V: Azure Speech in Foundry Tools, custom speech, batch transcription
