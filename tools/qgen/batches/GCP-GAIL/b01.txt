@ GCP-GAIL D1 T1.1 applied definition
S: A bank's executive team keeps hearing "AI", "machine learning" and "generative AI" used as if they were the same thing. A leader wants to explain how they relate. Which description is accurate?
A: Artificial intelligence is the broad field of making systems perform tasks that normally need human intelligence; machine learning is a subset that learns patterns from data; generative AI is a subset of machine learning that creates new content
B: Generative AI is the broad field that includes all intelligent software; machine learning is one of its products, and artificial intelligence is the name for the content that these models produce
C: Machine learning is the broad field of intelligent systems; artificial intelligence is a subset of it that uses data, and generative AI is the older rule-based approach it replaced
D: Artificial intelligence and generative AI are the same thing under two names, while machine learning refers only to storing historical data in a warehouse for reporting
K: A
G: ## Nested terms
These three terms are nested, like circles inside each other:
- **Artificial intelligence (AI)** is the broad goal: software that does tasks we associate with human intelligence, such as understanding language, recognizing images or making decisions.
- **Machine learning (ML)** is one way to reach that goal. Instead of writing explicit rules, you let a system learn patterns from data and then make predictions on new data.
- **Generative AI (gen AI)** is a branch of ML in which models learn the patterns in large amounts of data well enough to create new content: text, images, code, audio or video.
## Why leaders need this
A spam filter is ML but not generative: it classifies. A model that drafts a reply to the email is generative. Knowing the difference keeps projects scoped to the right technique.
W: Nested definition: AI is the umbrella goal, ML is the data-driven way to get there, and gen AI is the ML branch that produces new content, which matches how Google Cloud describes the three terms.
X: B=Gen AI as the umbrella: gen AI is the newest and narrowest layer, not the field that contains the others, and AI is not "the content models produce".
C=ML as the umbrella: ML sits inside AI, not above it, and gen AI is a modern ML technique, not the older rule-based approach.
D=Same thing / warehouse: AI is far broader than gen AI, and ML is about learning from data to make predictions, not storing data for reports.
T: AI is the field, ML learns from data inside it, gen AI is the ML branch that creates new content.

G: ## How diffusion works, in plain terms
A **diffusion model** learns by studying how images gradually turn into noise, then learns to reverse that process. To create an image it starts with random noise and removes the noise in many small steps, guided by the text prompt, until a coherent picture appears.
## Where this shows up
Diffusion is a common technique behind modern text-to-image generation. It creates new images; it does not retrieve or copy a stored image.
## Contrast
- Image search returns an existing item.
- Clustering (unsupervised learning) groups images.
- Compression shrinks files.
W: Denoising generation: starting from noise and refining it step by step under the guidance of the prompt is how diffusion models synthesize a new image.
X: A=Compression: shrinking files is a storage task and does not create new illustrations.
B=Library search: retrieval returns something that already exists, whereas the agency wants new artwork.
C=Unlabeled grouping: that is clustering, an unsupervised learning task, not image generation.
T: Diffusion models create images by iteratively denoising random noise toward the prompt.

@ GCP-GAIL D1 T1.1 applied definition
S: A product manager is told that an LLM usage report is measured in "tokens" and asks a colleague what a token is. Which answer is accurate?
A: A token is a security credential that proves a user is allowed to call the model
B: A token is a unit of text, such as a word, part of a word or punctuation mark, that the model reads and generates
C: A token is a complete sentence, so a 500-word document always counts as exactly 25 tokens
D: A token is a labeled example in the training set that tells the model the right answer
K: B
G: ## Tokens
LLMs do not read whole documents or even always whole words. Text is split into **tokens**: small chunks that can be a whole short word, a piece of a longer word, a number or a punctuation mark. The model reads input tokens and produces output tokens one at a time.
## Why business leaders care
- Usage and cost are commonly measured in tokens, so longer prompts and longer answers use more of them.
- A model can only consider a limited number of tokens at once (its context window), so very long inputs may not fit.
- Different languages and writing styles split into different numbers of tokens, so the count is not simply the word count.
Not to be confused with an authentication token, which is a security credential.
W: Unit of text: a token is a chunk of text the model reads or writes, which is why token counts drive length limits and usage measurement.
X: A=Credential: that is an access or authentication token, a different concept from the text units an LLM processes.
C=Sentence: a token is much smaller than a sentence, and token counts depend on how text splits, not on a fixed ratio.
D=Training example: a labeled example is a training data pair, not a text unit processed by the model.
T: Tokens are the chunks of text an LLM reads and writes, and they drive length limits and usage.

@ GCP-GAIL D1 T1.1 advanced comparison
S: A company has years of past loan applications, each marked "repaid" or "defaulted". It wants a model to predict the outcome for new applicants. Which machine learning approach applies, and why?
A: Unsupervised learning, because the model must discover default patterns without being told the outcomes

G: ## The three ML approaches
- **Supervised learning** trains on **labeled** data: each example has inputs (features) and the correct answer (label). The model learns the mapping so it can predict labels for new inputs. Typical tasks are classification (spam or not) and regression (a price).
- **Unsupervised learning** trains on **unlabeled** data and looks for structure on its own: clusters, associations or simpler representations.
- **Reinforcement learning** has an agent act in an environment and learn from rewards and penalties.
## Applying it
Past applications come with a known outcome, "repaid" or "defaulted". That is a labeled dataset and a classification task.
W: Supervised learning: the repaid/defaulted outcome is the label for each historical application, so the model learns from known answers and predicts for new applicants.
X: A=Unsupervised: it applies when no outcome labels exist; here labels exist and the goal is to predict one.
B=Reinforcement: it needs an agent acting in an environment with rewards, not a fixed set of historical records with outcomes.
D=Gen AI: predicting a category is a predictive task; it does not require generating new content.
T: Known outcomes in historical data mean labeled data, hence supervised learning.

@ GCP-GAIL D1 T1.1 applied definition
S: A communications team tells colleagues it is doing "prompt engineering" with an existing LLM. Which description of that work is accurate?
A: They are retraining the entire model on a new dataset so its internal weights change permanently
B: They are designing and refining the instructions, context and examples in the input they send, without changing the model itself, to get better outputs
C: They are building a new data warehouse so the model can retrieve numeric data faster
D: They are deploying the model to additional regions so responses arrive faster
K: B
G: ## Prompt engineering
A **prompt** is the input given to a model: instructions, context, examples and the question. **Prompt engineering** is the practice of designing and iterating on prompts so the model produces better, more reliable results. It needs no training: the model is unchanged, and only the input changes.
## Typical levers
- Clear task and format ("Summarize in three bullets for executives").
- Context and constraints (audience, tone, length).
- Examples of the desired output.
- Iteration: reviewing outputs and refining.
It is usually the fastest and cheapest first step before considering tuning.
W: Refining the input: prompt engineering improves results by shaping the instructions, context and examples while leaving the model's weights untouched.
X: A=Retraining: changing the model's weights through new training is tuning or training, not prompt engineering.
C=Data warehouse: a warehouse stores and queries data; it is infrastructure, not the design of prompts.
D=More regions: serving location affects latency and availability, not the quality of the output the prompt produces.
T: Prompt engineering improves outputs by improving the input, not the model.

@ GCP-GAIL D1 T1.1 advanced comparison
S: A team is told it can adapt an LLM in two ways, prompt engineering or prompt tuning. A leader wants the high-level difference. Which statement is correct?
A: Prompt engineering trains extra parameters on a labeled dataset, while prompt tuning means a person rewrites the wording by hand
B: Both terms mean writing better wording, and the only difference is that prompt tuning is done by developers
C: Prompt engineering changes the model's architecture, while prompt tuning only changes the font of the output
D: Prompt engineering adjusts the text of the prompt by hand, while prompt tuning trains a small set of added parameters on examples while the base model stays frozen
K: D
G: ## Two ways to steer a model without full retraining
- **Prompt engineering**: a person writes and iterates on the prompt text. No training, no data pipeline; the model is unchanged.
- **Prompt tuning**: a parameter-efficient tuning technique. A small set of learned values (a "soft prompt") is trained on example data and attached to the input, while the large model's own weights stay frozen. It needs a set of examples and a training run, but far less than retraining the entire model.
## Choosing between them
Start with prompt engineering because it is immediate and free of data needs. Consider tuning when careful prompts still fall short, and you have quality examples of the behavior you want.
W: Manual wording versus learned parameters: prompt engineering is hand-crafted text, while prompt tuning learns a small number of parameters from examples without modifying the base model.
X: A=Reversed: it assigns training to the manual approach and manual rewriting to the training approach, the opposite of how they work.
B=Same thing: they are different methods; one is a manual writing practice and the other is a training technique.
C=Architecture / font: neither technique alters model architecture, and neither is about output formatting appearance.
T: Prompt engineering = hand-crafted input; prompt tuning = learned small parameters with a frozen base model.

@ GCP-GAIL D1 T1.1 applied definition
S: An executive wants a one-slide picture of the machine learning lifecycle. Which sequence of stages is correct?
A: Data ingestion, model deployment, data preparation, model training, model management
B: Data preparation, data ingestion, model management, model training, model deployment
C: Model training, data ingestion, data preparation, model deployment, model management

G: ## Five stages
1. **Data ingestion**: collect data from sources into a place where it can be used (streams, files, databases).
2. **Data preparation**: clean, transform, label and organize the data so it is suitable for learning.
