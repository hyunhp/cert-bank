@ GCP-GAIL D2 T2.2 applied use-case
S: A company with thousands of knowledge workers wants a ready-made AI product, not a build project. IT wants to deploy it, set security policies, assign user licenses and connect data sources from across the organization, while employees search, chat and use agents in a web app. Which Google offering is aimed at this?
A: Gemini Enterprise, a prebuilt platform that administrators deploy and employees use for search, assistance and agents
B: Model Garden, a catalog where developers discover and deploy models and then build their own applications around them
C: AI Hypercomputer, an integrated infrastructure system for organizations that train and serve large models at scale
D: Google AI Studio, a web tool where developers prototype prompts and try Gemini models before building applications
K: A
G: ## Prebuilt AI "applications"
The exam's application layer holds finished products that people use without building anything. **Gemini Enterprise** is the one aimed at an organization's knowledge workers: administrators deploy and manage the platform, configure security policies, assign user licenses and connect enterprise data sources, while app users search enterprise data and work with AI assistants and agents in the web and mobile apps.
## How to tell it from the other layers
- **Applications** (Gemini Enterprise, Gemini for Google Workspace): used as they are, by people doing their jobs.
- **Platforms and models** (Model Garden, Agent Platform, Google AI Studio): used by developers who build or prototype solutions.
- **Infrastructure** (AI Hypercomputer, TPUs, GPUs): used by teams that train and serve models.
A company that wants a product to roll out, not a solution to build, needs an application.
W: Gemini Enterprise: it is a finished product that IT deploys and governs and that employees use directly, so no application has to be built.
X: B=Model Garden: it serves developers who select and deploy models, which is a build task, not a finished product for employees.
C=AI Hypercomputer: it is infrastructure for large-scale training and serving, which knowledge workers searching and chatting do not need.
D=Google AI Studio: it is a developer tool for trying Gemini models and prototyping, not an administrator-managed product for all employees.
T: Gemini Enterprise is the prebuilt product for employees; platforms and infrastructure are for builders.
V: Gemini Enterprise

Gemini Enterprise is a product that IT runs, so IT needs evidence that people use it and that it works. **Analytics** gives insight into the usage trends, search quality and end-user engagement of an app, in an interactive dashboard experience powered by Looker.

A: Sales team: Gemini Enterprise; HR: Gemini for Google Workspace; developers: Gemini Enterprise Agent Platform
B: Sales team: Gemini for Google Workspace; HR: Gemini Enterprise Agent Platform; developers: Gemini Enterprise
C: Sales team: Gemini Enterprise Agent Platform; HR: Gemini for Google Workspace; developers: Gemini Enterprise
D: Sales team: Gemini for Google Workspace; HR: Gemini Enterprise; developers: Gemini Enterprise Agent Platform
K: D
G: ## Who each offering is for
- **Gemini for Google Workspace**: people who work in Gmail, Docs, Slides and Sheets and want help inside those apps.
- **Gemini Enterprise**: employees of an organization, where IT connects company data and manages security and agents.
- **Gemini Enterprise Agent Platform**: developers who build their own solutions and applications from models and tools.
## Method
Ask three questions: who is the user (an individual, an employee, a developer), where does the work happen (a chat window, a productivity app, a company-wide set of systems, a custom product), and who manages it (the user, IT or a development team).
W: Workspace, Gemini Enterprise and Agent Platform: in-app help, permission-aware company-wide answers, and building a customer-facing product match these three in order.
X: A=Enterprise for the sales team: this puts a company-wide product on a need for help inside the productivity apps and gives HR in-app help instead of search across company systems.
B=Agent Platform for HR and Enterprise for developers: HR wants a ready-made assistant rather than a build platform, and developers embedding models need a build platform.
C=Agent Platform for the sales team: a developer platform is excessive for in-app writing help, and Workspace help does not search connected company systems for HR.
T: Staff in Gmail and Docs = Workspace; employees on company data = Gemini Enterprise; developers building products = Agent Platform.
V: Gemini for Google Workspace, Gemini Enterprise, Gemini Enterprise Agent Platform

@ GCP-GAIL D2 T2.2 applied troubleshooting
S: A Gemini Enterprise administrator learns that one internally built agent is giving unreliable answers. She wants to switch it off for now so nobody can use it, but employees should still see it in the Agent Gallery with a message explaining why it is unavailable, and its owner must keep full access to fix it. Which agent state fits?
A: Enabled, because the agent is active and every authorized user can interact with it as intended
B: Deleted, because removing the agent from the Agents page also removes it from the web app
C: Private, because only the creator can chat with the agent and other users cannot see it at all
D: Suspended, because the agent is temporarily deactivated yet stays visible with an explanation
K: D
G: ## Managing agents centrally
Gemini Enterprise gives administrators one place to oversee agents from Google, third parties and internal teams. Each agent has a state:
- **Enabled**: active and usable by authorized users.
- **Private**: for personal use; only its creator can chat with it.
- **Suspended**: temporarily deactivated. It remains visible in the Agent Gallery with a message explaining the deactivation; users cannot interact with it, but owners and admins keep full access.
- **Disabled**: inactive and hidden from the Agent Gallery until the owner or an admin re-enables it.
## Why it matters
A weak agent can be paused without losing it, and users are told what happened instead of wondering where it went. Deleting is permanent removal, which is more than the administrator wants.
W: Suspended: the agent is deactivated for users, yet still listed with a message, and the owner and admins can keep working on it.
X: A=Enabled: the agent would stay in use, which is what the administrator wants to stop.
B=Deleted: removal takes the agent off the Agents page and the web app, so it cannot be fixed and users get no explanation.
C=Private: this is a personal-use state, not a way to show a deactivated agent with a message to all employees.
T: Suspended = temporarily off for users, still listed with an explanation; Disabled hides it; Delete removes it.
V: Gemini Enterprise
