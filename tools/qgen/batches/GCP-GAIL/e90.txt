G: ## Data preparation
Models learn from whatever the data teaches them, so inconsistent or incomplete data leads to poor models. Data preparation includes cleaning, removing duplicates, handling missing values, standardizing formats and units, joining sources, and labeling.
## Tools
- **Dataflow**: scalable pipelines that transform streaming or batch data.
- **BigQuery**: SQL-based transformation and analysis of large structured datasets.
- **Dataproc**: managed Apache Spark and Hadoop for teams with existing jobs.
- **Managed datasets on Agent Platform** (formerly Vertex AI): organize image and tabular data for training.
## Stage check
Data is already ingested; it needs cleaning. That is preparation, not ingestion or deployment.
Current name: Dataproc is now documented as Managed Service for Apache Spark. The exam guide and this question keep the older name.
W: Preparation with Dataflow or BigQuery: cleaning duplicates, filling gaps and standardizing units are preparation tasks, and these services transform data at scale.
X: A=Management/drift: monitoring is for models in production and not for cleaning raw training data.
B=Ingestion with Pub/Sub: Pub/Sub moves messages and does not clean or normalize them; the data has also already arrived.
C=Deployment: serving predictions comes after a model is trained, and it does not clean raw data.
T: Cleaning and transforming data is preparation: Dataflow, BigQuery or Dataproc.

G: ## Stage-to-tool map
- **Ingestion**: Pub/Sub (streams), Cloud Storage (files), Dataflow (moving data).
- **Preparation**: Dataflow, BigQuery, Dataproc, managed datasets.
- **Training**: AutoML, custom training, Workbench on Agent Platform.
- **Deployment**: Agent Platform endpoints for online and batch inference.
- **Management**: Model Registry, Pipelines, Model Monitoring, Feature Store.
## How to eliminate
Ask what the service fundamentally does. Messaging does not train; a dashboard tool does not serve predictions; a model repository does not collect raw data.
Current name: Dataproc is now documented as Managed Service for Apache Spark. The exam guide and this question keep the older name.

E=Preparation tools: Dataflow and BigQuery transform and clean data at scale, which is the preparation stage.

B=Model Registry for ingestion: it holds trained model versions, not incoming data.
C=Looker Studio for deployment: it visualizes data and does not serve model predictions to applications.
