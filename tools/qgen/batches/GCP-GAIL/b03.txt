@ GCP-GAIL D1 T1.3 applied definition
S: A consultant explains the gen AI landscape to a retailer's leadership team as a stack of five layers. Which list shows the layers in order from the foundation up to what employees and customers see?
A: Infrastructure, models, platforms, agents, applications
B: Models, infrastructure, applications, platforms, agents
C: Platforms, infrastructure, models, applications, agents
D: Infrastructure, platforms, models, applications, agents
K: A
G: ## The five layers of the gen AI landscape
Leaders find it easier to compare gen AI offerings when they sort them into layers. Each layer builds on the one below it:
- **Infrastructure**: the compute that trains and runs models, such as data centers, accelerators (GPUs, TPUs), networking and storage.
- **Models**: the foundation models that understand and generate content, for example Gemini for multimodal tasks.
- **Platforms**: the environment where developers find, tune, ground, evaluate and deploy models, for example Gemini Enterprise Agent Platform (formerly Vertex AI).
- **Agents**: systems built on models that pursue a goal, plan steps and use tools or data to act.
- **Applications**: finished products that people use directly, such as the Gemini app or Gemini for Google Workspace.
## Why the order matters
Every upper layer depends on those below it, and each step up usually means less to build and operate, but also fewer choices to control.
W: Infrastructure, models, platforms, agents, applications: compute comes first, models run on it, platforms let teams build with models, agents use models to act, and applications put the result in front of users.
X: B=Models first: models cannot run without compute underneath, so infrastructure sits below them, and agents sit before the applications that deliver them to users.
C=Platforms first: a platform needs models and compute to offer anything, so it cannot be the foundation of the stack.
D=Platforms before models: developers use a platform to work with models, so models come first; and agents come before the applications that present them.
T: Bottom to top: infrastructure, models, platforms, agents, applications.
V: Gemini Enterprise Agent Platform

@ GCP-GAIL D1 T1.3 applied use-case
S: A chief financial officer asks which layer of the gen AI landscape contains the specialized accelerators, such as TPUs and GPUs, that a company would pay for when training or serving large models. What is the answer?
A: Models, because the accelerators are part of each trained model's weights
B: Infrastructure, because accelerators, data centers and networking supply compute

G: ## What the infrastructure layer contains
The infrastructure layer is the physical and virtual compute that everything else runs on: data centers, networking, storage and AI accelerators such as GPUs and Google's TPUs. Organizations that train very large models or serve huge request volumes care about this layer most, because accelerator availability and efficiency drive speed and cost.
## Business implication
Most companies do not buy accelerators directly. They consume them through managed services higher in the stack, which means they benefit from the infrastructure layer without owning it. Only teams building or customizing their own models at scale decide about it explicitly.
W: Infrastructure: TPUs, GPUs, data centers and networking are the compute resources that train and run models, which makes them the bottom layer.
X: A=Models: a model is a trained artifact (learned weights); it runs on accelerators but does not contain them.
C=Platforms: a platform offers tools to build with models and can hide the hardware choice, but the hardware itself belongs to the infrastructure layer.
D=Applications: end users see a finished tool, not the accelerators; hiding that hardware is the point of the top layer.
T: Chips, data centers and networking = infrastructure layer; most businesses consume it through higher layers.

@ GCP-GAIL D1 T1.3 applied use-case
S: A bank's developers want one governed environment where they can find a model, tune it on company data, test it, and deploy it behind an application, without building the tooling themselves. Which layer of the gen AI landscape provides this?
A: The infrastructure layer, where the bank's engineers would assemble their own training clusters, pipelines and deployment tooling

C: The platform layer, such as Gemini Enterprise Agent Platform, with model access, tuning and deployment

G: ## What the platform layer does
A platform sits between raw models and finished products. It gives developers the tools to **find** models (for example through Model Garden), **customize** them (prompting, grounding, tuning), **evaluate** them, and **deploy** them with security and access control. On Google Cloud this is Gemini Enterprise Agent Platform, which was previously named Vertex AI.
## Business implication
A platform shortens the path from idea to production and gives the company one place for governance. The trade-off is that someone still has to build and maintain the solution, unlike an application that is ready to use.
W: Platform layer: a platform bundles model access, tuning, evaluation and deployment with governance, so developers do not need to build that tooling themselves.
X: A=Infrastructure: it supplies raw compute, but assembling clusters and tools by hand is the effort the bank wants to avoid.
B=Applications: a ready-made assistant helps end users but is not an environment in which developers tune and deploy their own model.
D=Model layer: a model produces output but has no tools for tuning, evaluating or deploying itself; those come from the platform around it.
T: Developers who need to find, tune, test and deploy models in one governed place need the platform layer.
V: Gemini Enterprise Agent Platform

@ GCP-GAIL D1 T1.3 applied definition
S: An insurer's executive wants a system that, given the goal "resolve this customer's claim question", can plan the steps, look up the policy in internal systems, call a tool to check status, and reply. Which layer of the gen AI landscape does this capability describe?
A: The models layer, because a foundation model alone looks up policies and calls tools
B: The agents layer, because agents reason toward a goal and act through tools
C: The infrastructure layer, because calling tools is a function of networking hardware
D: The applications layer, because every system that talks with customers or employees belongs only to that layer of the stack
K: B
G: ## What makes something an agent
A **model** responds to a prompt with generated content. An **agent** wraps a model with the ability to:
- **Reason and plan**: break a goal into steps.
- **Use tools and data**: call systems, search content, run functions.
- **Act**: carry out steps, check results and continue until the goal is met or a human is needed.
So the agents layer sits above the models layer and below the applications that present agents to users.
## Business implication
Agents move gen AI from answering questions to completing tasks, which can automate multi-step work. They also need more care: access to systems, permissions and human oversight must be planned.
W: Agents layer: planning steps, looking up policies and calling tools to reach a goal are what distinguishes an agent from a model that only generates a reply.
X: A=Models layer: a model generates content from its input; planning across steps and using external tools is added by the agent built around it.
C=Infrastructure layer: networks and chips carry traffic, but deciding which tool to call is a software and model behavior, not a hardware function.
D=Applications layer: an agent may appear inside an application, but the reasoning-and-acting capability is the agent layer; the application is the product wrapper.
T: Goal, plan, tools, action = agents layer, above models and below the applications users see.

@ GCP-GAIL D1 T1.3 advanced tradeoff
S: A marketing team with no developers wants to draft emails, summarize documents and prepare slides this quarter, using the tools its staff already work in. Leadership accepts that they will have limited ability to customize the underlying model. Which layer should the company start from?
A: The applications layer, using a ready-made product such as Gemini for Google Workspace
B: The infrastructure layer, by renting accelerators and training a company-specific model
C: The platform layer, by building a custom drafting tool on a development platform
D: The models layer, by calling a foundation model directly from each employee's browser
K: A
G: ## Moving up or down the stack
Choosing a layer is mostly a trade-off between **speed and effort** and **control**:
- Higher layers (applications, agents) are closer to ready to use: little to build, fast time to value, but fewer ways to change how they behave.
- Lower layers (platforms, models, infrastructure) offer more control and customization, but need skills, time and ongoing operation.
## Reading the scenario
No developers, a goal for this quarter, and acceptance of limited customization all point to the top of the stack. An application such as Gemini for Google Workspace puts gen AI inside Gmail, Docs and Slides, where staff already work.
W: Applications layer: a ready-made product such as Gemini for Google Workspace needs no development, fits the tools staff already use, and delivers value quickly, which is the trade the team accepts.
X: B=Infrastructure and custom training: it gives maximum control but needs specialist skills and long timelines that a team with no developers cannot meet.
C=Platform and custom tool: a platform shortens building but still requires developers to design, test and run a solution, which this team does not have.
D=Calling a model directly: calling a model through an API requires development, and a bare model lacks the user interface and controls employees need.
T: No developers and a quick start with limited customization = start at the applications layer; more control costs more effort.
V: Gemini for Google Workspace

S: A mobile app maker wants a small generative model that can run directly on its users' phones, so that features work without sending every request to a cloud service, and wants to adapt it to the app's tasks. Which Google model family is the best starting point?
A: Veo, because its video models are designed to run offline inside phone apps

K: D
G: ## Where open models fit
Google documents that Gemma models can run in your applications and on your hardware, **mobile devices** or hosted services, and that they can be tuned to excel at particular tasks. Keeping inference on the device can reduce latency and the amount of data sent to a cloud service, at the cost of the team handling packaging, tuning and updates.
## Why not the others
Gemini is used as a Google service and is not an open model you install; Imagen and Veo generate images and video and are not the open, tunable language options.
W: Gemma: it is a lightweight open family that Google documents as able to run on mobile devices and that teams can tune for their own tasks, which matches an on-device feature.
X: A=Veo: it is a video generation family and is not described as an on-device model for phone apps.
