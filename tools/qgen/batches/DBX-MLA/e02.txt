G: ## What summary() does
Without arguments, `summary()` computes count, mean, stddev, min, approximate quartiles (25%, 50%, 75%) and max for every numeric and string column of the DataFrame. It is an aggregation over the whole data, so the work grows with the number of columns and the size of the data.
- Narrow the DataFrame with `select` before summarizing. Spark then reads and aggregates only the chosen columns, and for columnar sources such as Delta it can skip other columns on disk.
- Ask for fewer statistics by naming them, for example `summary("count", "mean")`, if you do not need the whole default list.
## Other points
`describe()` and `summary()` are both aggregations that scan the data, and neither is free. Caching helps only if the data is reused many times, and it adds the cost of materializing all 600 columns.
W: Select the two columns first: Spark then computes statistics for 2 columns instead of 600, and with a columnar source it avoids reading the rest.
X: A=`describe()`: it also aggregates all columns by scanning the data. It computes fewer statistics but still all 600 columns.
B=`cache()`: the first pass still has to read and materialize all 600 columns. Caching pays only when the same data is used repeatedly.
D=Adding a percentile: extra statistics add work. They do not prune columns.
