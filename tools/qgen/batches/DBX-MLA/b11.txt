G: ## Which experiment a search looks at
`mlflow.search_runs()` accepts `experiment_ids` **or** `experiment_names`. When both are empty, it searches the **active experiment**. ## Other parameters in the options
- `run_view_type` defaults to active runs only; deleted runs are simply excluded and never hide active ones.
- `experiment_names` takes names; a notebook experiment's name is the notebook path, not its numeric ID.
- `search_all_experiments=True` is honored only when `experiment_ids` is empty.

A: The 1.5 x IQR rule with bounds of -50 and 190 minutes, which keeps the 185-minute record and removes the 200-minute record
B: The 1.0 x IQR rule with bounds of -20 and 160 minutes, which removes both the 185-minute record and the 200-minute record
C: The 3-standard-deviation rule with bounds of -27 and 183 minutes, which removes both the 185-minute record and the 200-minute record

G: ## Working the numbers
- **IQR** = Q3 - Q1 = 100 - 40 = 60.
- **1.5 x IQR rule**: lower = 40 - 90 = **-50**, upper = 100 + 90 = **190**.
- **1.0 x IQR**: lower = 40 - 60 = -20, upper = 100 + 60 = 160.
- **3-sigma rule**: 78 +/- 3 x 35 = 78 +/- 105 -> **-27 to 183**.
- **2-sigma rule**: 78 +/- 70 -> 8 to 148.

The data is right-skewed (mean 78 is above the midpoint of Q1 and Q3), so the standard deviation is inflated by the tail while the quartiles are not. C=3 standard deviations: the upper bound is 183, so the genuine 185-minute delivery is removed.
D=2 standard deviations: the upper bound is 148, which removes many genuine long deliveries, including 185.
T: Work the bounds: 1.5 x IQR = Q1 - 1.5 x IQR to Q3 + 1.5 x IQR; on skewed data quartile rules behave differently from sigma rules.

G: ## What DataFrame.summary() computes
`summary()` with no arguments returns `count`, `mean`, `stddev`, `min`, **approximate** quartiles (`25%`, `50%`, `75%`) and `max` for numeric and string columns.
- **count** counts **non-null** values: 10,000,000 - 9,412,000 = 588,000 nulls in `age`.

X: B=Gold missing: string min and max are alphabetical; Gold sorts between Bronze and Silver, so this output says nothing about it.
