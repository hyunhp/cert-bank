# SAP-C02 availability notes: AWS Directory Service Simple AD closed to new customers 2026-07-30; explanation-only updates, letters are the published ones

@ Q001189 explain
G: ## AWS Directory Service options
- **AD Connector**: a directory gateway (proxy). It forwards authentication and directory requests from AWS services to your **existing on-premises Active Directory**. No directory data is stored or cached in AWS.
- **AWS Managed Microsoft AD**: a real Microsoft Active Directory run by AWS. It is a **new, separate** directory; to use on-premises identities you set up a trust relationship.
- **Simple AD**: a standalone, Samba-based directory with basic AD-compatible features. It does not support trusts and does not replicate from other directories. It closed to new customers on 2026-07-30; AWS directs new directories to AWS Managed Microsoft AD.
## Choosing
If the requirement is "use the directory we already have, and do not create another one", AD Connector is the fit. EC2 Windows instances can join the on-premises domain through it, and supported AWS services authenticate users against on-premises AD. It requires network connectivity to the domain controllers, such as VPN or Direct Connect.
W: AD Connector: it proxies requests to the existing on-premises Active Directory, so AWS-based servers use the same directory with no second directory to create or synchronize.
X: A=AD Connector and Managed Microsoft AD are identical: Managed Microsoft AD creates and runs a new directory in AWS, while AD Connector only forwards requests to an existing one.
B=Simple AD replicates on-premises AD: Simple AD is standalone; it does not replicate objects from or trust an on-premises AD. It is also closed to new customers since 2026-07-30, so a new deployment could not choose it anyway.
D=Managed Microsoft AD because AD Connector cannot serve Windows apps: AD Connector does support domain join and authentication against the existing AD; choosing Managed AD would create the separate directory the company wants to avoid.
T: Use AD Connector to reuse an existing on-premises directory; use AWS Managed Microsoft AD when you need an actual AD running in AWS.
