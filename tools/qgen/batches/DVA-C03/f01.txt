G: ## Event-driven automation with agent hooks
Kiro **hooks** run an action automatically when a specific event happens in a session. Each hook is a JSON file in `.kiro/hooks/` (for example `.kiro/hooks/update-tests.json`) with three parts:
- **Trigger**: the event, such as `PostFileSave` (File Save in the IDE), `PostFileCreate`, `PostFileDelete`, `PreToolUse`, `PostTaskExec` or `Stop`.
- **Matcher** (optional): for file events, a regular expression matched against the file path, for example `src/handlers/.*\.ts$`.
- **Action**: either `agent`, which sends a prompt to the agent ("update the unit tests that cover this handler"), or `command`, which runs a shell command such as `npx eslint --fix`.
## What the file triggers react to
Since Kiro IDE 1.0, the file triggers fire when the **agent** creates, saves or modifies a matching file (the 0.x trigger `fileEdited` became `PostFileSave`). Hooks activate automatically when a session starts, so the follow-up runs every time without anyone remembering to ask. Typical uses are tests, documentation, translation files and lint fixes.
## Compared with other Kiro features
- **Steering** files give the agent standing guidance; an always-included file shapes what the agent writes, but nothing is triggered by a file event.
- A **manually included** steering file is loaded only when someone references it, for example as a `/<filename>` slash command in chat.
- **Specs** plan a feature as tasks in `tasks.md`; their steps run when the tasks are executed, not on each save.
W: Agent hook on File Save: the `PostFileSave` trigger fires each time the agent saves a matching file, the matcher limits it to TypeScript files under `src/handlers`, and the agent prompt action tells the agent to update the corresponding tests, which is the automatic, event-driven step the developer asked for.
X: A=Steering for new handlers: the steering text only influences what the agent writes, and as worded it covers newly generated handlers, so edits to existing handlers trigger nothing and tests can still be forgotten.
