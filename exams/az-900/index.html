D1 · Describe cloud concepts 27.5%

Cloud concept questions describe a company situation in plain business terms (an outage below the SLA, seasonal demand, a mix of services, attacks a small team cannot stop) and ask which model, benefit or category it shows. No configuration is involved. The challenge is choosing the most exact term among several that sound partly right.

What to watch for

  • An SLA defines what the customer can claim when a target is missed. Be careful with options that promise more than that.
  • Sort services into IaaS, PaaS and SaaS by how much the customer still manages. A single solution can use all three.
  • Cloud benefits such as security and governance have specific meanings, for example standard templates and continuous auditing for drift.

D2 · Describe Azure architecture and services 37.5%

This domain names Azure building blocks and asks which one fits a short requirement: a datacenter failure inside one region, remote laptops reaching private VMs, schemaless device records, or a security principle. Answers depend on knowing what each service is for. Close distractors are services in the same family that work at a different scale or for a different kind of data.

What to watch for

  • Match the scope of protection to the failure: availability sets cover racks inside a datacenter, availability zones cover a whole datacenter in a region.
  • For VPN questions, ask what connects: one device at a time, or an entire on-premises network.
  • Learn the Azure Storage services by the shape of their data: objects, VM disks, messages, key-based records and shared folders.

D3 · Describe Azure management and governance 32.5%

Management and governance items are short and practical. They name a task (writing log queries, scripting for a Windows team, tracing data lineage, onboarding on-premises servers) or a puzzling result such as untagged resources, and ask which tool or behavior explains it. The right answer is the tool built for that exact job; the others are real Azure tools with different purposes.

What to watch for

  • Choose between Azure PowerShell and Azure CLI by the team's existing skills; both manage the same resources.
  • Tags do not flow down from a resource group. Expect Azure Policy or direct tagging whenever inherited tags are assumed.
  • Servers outside Azure, such as machines in a company datacenter, need an agent installed before Azure Arc can manage them as Azure resources.
