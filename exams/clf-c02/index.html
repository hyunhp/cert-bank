D1 · Cloud Concepts 24%

Cloud Concepts questions use everyday business situations to test the value of the cloud, the Well-Architected pillars and migration choices. Each scenario hints at one benefit, principle or strategy, and you pick its name. The options are often all true statements about AWS, so the winner is the one that fits the situation described, not the most impressive one.

What to watch for

  • Match the scenario to a Well-Architected pillar by its main goal. Reducing energy use belongs to Sustainability even when it also lowers cost.
  • When the database engine changes during a migration, moving the data is only half the job; the schema and code objects need converting as well.
  • Manual, error-prone runbooks point to automating operations as code, so that every run happens the same way.

D2 · Security and Compliance 30%

Security and Compliance items test who is responsible for what, and which AWS service or IAM feature handles a given task. A scenario might ask about patching, granting permissions to a team, finding a troubleshooting article or reading a policy. Pay attention to the actor and the action, because the wrong options are usually real services that serve another purpose.

What to watch for

  • Under the shared responsibility model, the more managed or serverless the service, the less the customer secures; data, code and permissions always stay with the customer.
  • Learn the parts of an IAM policy statement (Effect, Action, Resource, Condition), and use groups when several users need the same permissions.
  • Sort the security services by target: Macie for sensitive data in S3, Inspector for software vulnerabilities, and Security Hub CSPM to gather findings in one view.
Tasks in the official exam guide (4)

  • 2.2 AWS Cloud security, governance, and compliance concepts
  • 2.3 AWS access management capabilities
  • 2.4 Components and resources for security

D3 · Cloud Technology and Services 34%

This is the widest domain, covering global infrastructure, compute, storage, databases, networking, analytics and backup. Most questions describe a need in a sentence or two and ask for the matching service, and close pairs are the challenge: a cache and a durable in-memory database, querying files and running a warehouse, a queue and a topic. Details in the requirement separate them.

What to watch for

  • Regional resources that seem to vanish in the CLI are usually being looked for in another Region. Check the configured Region before suspecting a fault.
  • Customer data stays in the Region chosen for it unless the customer copies or replicates it, so picking the Region is how data residency is met.
  • When one central place must manage a task across many services and accounts, look for the AWS service built for that task rather than per-service settings.

D4 · Billing, Pricing, and Support 12%

Billing questions ask how a charge is calculated, which tool answers a cost question, or which kind of help AWS offers. Scenarios include Savings Plans, data transfer, rightsizing and large migrations. The detail that decides is often timing or direction: estimating before building versus analyzing past spend, or data coming into AWS versus leaving it.

What to watch for

  • A Savings Plan discounts usage only up to the hourly commitment. Anything above that amount is billed at On-Demand rates.
  • Track the direction and path of data transfer. Inbound traffic and private traffic inside one Availability Zone are priced differently from traffic to the internet or between Regions.
  • Separate the cost tools by purpose: Pricing Calculator estimates, Cost Explorer looks back, Budgets alerts, and Compute Optimizer suggests better sizes from real use.
