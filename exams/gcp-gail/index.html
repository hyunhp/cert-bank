D1 · Fundamentals of gen AI 30%

Fundamentals questions use business cases to check gen AI vocabulary: which Google model family fits a media task, which layer of the landscape a team needs, why a tuned model behaves badly. The answer usually depends on one concept, such as modality, data labels or the order in which to try customization. Options that jump to heavy work too early are often wrong.

What to watch for

  • Try the lightest customization first: prompt changes need no training, while tuning only makes sense once consistent labeled examples exist.
  • Read what goes in and what must come out. Mixed inputs such as text, photos and scans call for a multimodal model, and image work and video work each have their own model family.
  • When a tuned model behaves inconsistently, examine the labels before the model; two teams using different names for the same case leave it with conflicting signals.

D2 · Google Cloud's gen AI offerings 35%

Product choice is the focus. A team describes what it wants (custom hardware for large models, a managed API for an open model, control over an internal agent, help for customer service) and you match it to the Google Cloud offering. Close options are usually neighbouring products or settings, so details about control, effort and lifecycle status decide.

What to watch for

  • In Model Garden, separate calling a model through a managed API from deploying it to your own endpoint; how much infrastructure the team wants to run decides.
  • Check a tool's lifecycle before picking it: a deprecated API is a poor base for new work, even if it once fit the task well.
  • For agent administration in Gemini Enterprise, read what users should still see; suspending, disabling and deleting an agent differ in visibility and permanence.

D3 · Techniques to improve gen AI model output 20%

This domain is about making model output reliable and fair. Situations include inconsistent layouts, risky drafts sent to customers, biased wording and features computed differently for training and serving. You choose the technique that targets the actual cause, and the trap is a change that sounds powerful but leaves the cause in place, such as a bigger model for a bias problem.

What to watch for

  • Classify the data source first: content the company owns, content licensed from a provider, and public world knowledge each lead to a different grounding route.
  • For high-stakes output, pair grounding in approved sources with human review of the drafts; either measure alone still leaves a gap.
  • Treat format and bias differently: a format is fixed with clearer instructions, while bias must be measured across groups and then reduced with data, prompts, tuning and oversight.

D4 · Business strategies for a successful gen AI solution 15%

Leaders face decisions about building, securing and governing gen AI. The stems describe a proposal (train from scratch, add security later, share one credential) or a worry about privacy, and ask which response follows Google Cloud's guidance. Correct options tend to start small and measured, build security in early, and give each component only the access it needs.

What to watch for

  • Be cautious of plans that build a model from scratch or postpone controls to save time; the guidance favours pre-trained models and security from design onward.
  • For agents that call internal systems, think in terms of identity: a separate identity per agent with narrow permissions makes every action traceable.
  • Privacy questions centre on personal data being used beyond its purpose; handling rules and submitting less data address the risk better than a general promise of care.
